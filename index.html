Hermes Calendar

A private, single-user plugin that reads Google Calendar events and keeps events on calendars its operator has made writable.

What it does

Hermes Calendar is a personal assistant plugin. It lets its single operator ask questions about their own calendar — what is scheduled today, when a given event starts, whether a time slot is free — and answers them by reading events from a small, fixed list of Google calendars the operator has explicitly allowed.

On the few calendars the operator has also made writable, it can place, move and remove events for the operator, for example to keep the sessions of a training plan in a dedicated calendar. It writes only after the operator has agreed to the change.

How it accesses Google Calendar

  • It signs in as one dedicated Google account, and only reaches calendars the operator has shared with that account and listed in the plugin's own configuration.
  • For reading, it uses the read-only scope https://www.googleapis.com/auth/calendar.events.readonly.
  • For writing, it uses a separate grant with the scope https://www.googleapis.com/auth/calendar.events. It writes only to calendars listed as writable in its configuration and shared with edit rights for events. Every other calendar is shared read-only, so Google itself refuses any change to it.
  • It never sends invitations or notifications, and does not create recurring events or events with guests.
  • It runs on the operator's own machine. There is no server, no shared deployment, and no other user.

Who it is for

One person: its operator. It is not offered to the public, has no sign-up, and is not distributed as a product.
