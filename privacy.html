Privacy Policy

Hermes Calendar Reader — last updated 17 September 2026

Hermes Calendar Reader ("the app") is a private, single-user application operated by one individual for their own use. This policy describes how it handles Google user data.

What data the app accesses

The app requests one OAuth scope, https://www.googleapis.com/auth/calendar.events.readonly. With it, the app reads calendar events — titles, times, locations, descriptions, and attendance status — from a fixed list of calendars that the operator has shared with the app's dedicated Google account and listed in the app's configuration. The app reads no other calendars and requests no other Google data. The scope is read-only, so the app cannot create, modify, or delete calendar data.

How the data is used

Calendar data is used solely to answer the operator's own questions about their schedule, in the moment they are asked. It is not used for advertising, profiling, analytics, or training any model, and it is not used to build any user profile.

How the data is stored

The app runs on the operator's own computer. Calendar event data is held in memory only for the duration of a request and is not written to any database or long-term store by the app. The OAuth refresh token issued by Google is stored locally on that machine, with file permissions restricted to the operator, so the app can keep reading the allowed calendars without repeated sign-in.

How the data is shared

Calendar data is not sold, rented, or shared with any third party. It is shown only to the operator, who is also the account holder whose calendars are being read. When the operator asks a question, the relevant event details are sent to the language-model provider that powers the operator's assistant, purely to phrase the answer; no other recipient receives the data.

Data retention and deletion

Because no calendar data is retained, there is nothing to delete beyond the stored OAuth token. The operator can revoke the app's access at any time from their Google Account's linked-apps settings, which immediately ends the app's ability to read any calendar, and can delete the locally stored token.

Limited Use

Hermes Calendar Reader's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Children

The app has exactly one user, its adult operator. It is not directed at children.
